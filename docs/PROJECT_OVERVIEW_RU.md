# ИИ-Ассистент — обзор проекта

## Идея

ИИ-Ассистент создаётся как персональный цифровой помощник, способный понимать сообщения пользователя, хранить структурированный контекст и безопасно выполнять действия. Планирование времени — первая развитая предметная область, а не граница продукта.

## Задача

Обычный LLM хорошо понимает язык, но его свободный ответ не должен становиться источником истины для календаря, памяти или других пользовательских данных. Поэтому проект разделяет понимание языка и исполнение действий.

LLM отвечает за интерпретацию. Код отвечает за вычисления, проверку ограничений, валидацию, транзакции и сохранение данных.

## Текущий функциональный фокус

Система проектируется для работы с событиями, задачами, сроками, регулярным расписанием, напоминаниями, людьми и связанными с ними фактами, конфликтами времени, временем на дорогу и пользовательскими предпочтениями.

## Направление развития

Архитектура предполагает подключение дополнительных доменов и сервисов без превращения LLM в непосредственного исполнителя операций. Новые возможности должны подключаться через проверяемые application/domain interfaces и политики исполнения.

## Надёжность

Ключевые решения проекта: детерминированное время и конфликты, provenance значимых данных, транзакционные изменения, идемпотентность, разделение Proposal и Policy, а также многоуровневое автоматизированное тестирование.

## Публичная версия

Этот репозиторий предназначен для демонстрации проекта и его архитектуры. Он не содержит production-кода, секретов, пользовательских данных и эксплуатационной конфигурации.
